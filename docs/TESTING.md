# 团队测试指南

给参与测试的同事。操作步骤、名词解释和常见问题请先看 [用户使用手册](USER_GUIDE.md)，本文只说明**测什么、怎么记录、已知情况**。

- 页面：https://monadpro.github.io/Pulse/ （Chrome + MetaMask，无需安装或运行代码）
- 网络：Monad 测试网（chainId 10143），所有币都是测试币
- 合约地址：见 [README](../README.md)，均已在 MonadVision 验证

## 一、测试前准备（每人一次）

1. 安装 MetaMask，**新建一个测试专用钱包**，不要用有真钱的钱包。
2. 领 MON（手续费币）：到 https://faucet.monad.xyz 粘贴地址领取。官方没有写明这个水龙头的额度和限制，领不到时可以在终端用下面的命令，把地址换成你自己的：

```sh
curl -s -X POST https://agents.devnads.com/v1/faucet -H "Content-Type: application/json" -d '{"chainId":10143,"address":"你的钱包地址"}'
```

   这个接口每次发 1 MON，只需要地址，不需要私钥。每笔操作约花 0.01–0.03 MON，1–2 MON 够测一轮。
3. 打开页面，按用户手册"第四章"连接钱包、领测试代币。

## 三、已知情况（先看，避免重复反馈）

- **钱包交互还没有人在真实浏览器里测过。** 第 1 到 10 项的按钮，我们只验证过合约和命令行流程，所以你们遇到的问题很可能是第一手的，请重点记录。
- **时间轴的颜色**：黄、蓝、绿能正常显示，但没有确认它用的是 `monadNewHeads` 的真实区块状态，还是按区块高度推算的。看起来正常即可。
- **公共节点会限流**：页面卡住或交易失败时，等几秒刷新再试。
- **订阅从打开页面开始**：刷新后时间轴会重新开始，不会回填历史区块。
- **攻击对比是模拟**：它用一个合约扮演"可以任意调整区块内交易顺序的出块者"，用来展示机制差异，不代表 Monad 上真实发生了攻击。
- **公共 AMM 的状态会被改变**：多次点左边"运行攻击"，AMM 的池子会变化，结果数字和第一次会有差异，属于正常现象。
- 网络上目前只有我们自己的合约，没有真实资金，也不会有真实损失。

- **Coinbase Wallet 插件可能弹出"该网站可能不安全"**：这是 Coinbase 插件的风险名单把新的 `github.io` 子域名先标成了可疑，不是页面程序的问题。自己测试时可以点"继续前往网站"，或者只启用 MetaMask。页面现在会让你在多个钱包里选择，默认优先 MetaMask。
- **买入要有 pUSD，卖出要有 pMON**：下单前先点对应的"领"按钮。余额不足时页面会提示，并禁用授权和提交按钮。
- **授权额度是 100,000，不是无限额度**，用完需要再授权一次。
- **查交易**：每次操作后，下单区下方会显示最近一笔交易的哈希，点开就是 MonadVision；旁边还有"查看我的全部交易"的链接。

## 四、反馈问题

请发给负责人，包含：

1. 测试项编号和具体做了什么；
2. 页面提示的错误文字，或截图；
3. 浏览器控制台（F12，看 Console）里的红色报错；
4. 你的钱包地址（方便在浏览器里查交易）。**不要发助记词或私钥。**

## 五、安全提醒

- 所有币都是测试币，没有价值。
- 任何人都不应该向你要助记词或私钥，Pulse 不需要，也不会要。
- 部署用的钱包私钥只在负责人本机的 `.env` 里，同事不需要它。
