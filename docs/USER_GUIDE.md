# Pulse 使用手册（新手版）

不需要懂区块链，跟着做就能玩。全程大约 10 分钟。

---

## 一、Pulse 是什么？

想象一个**拍卖会**：

- 区块链每 0.3 秒"出一个块"，可以理解为**每 0.3 秒开一场拍卖**。
- 这 0.3 秒里，所有人提交的买单和卖单会被放在一起。
- 拍卖结束时，系统算出**一个统一的价格**，所有成交的订单**都按这个价格**交易。

**这有什么好处？** 在普通交易所里，有人能抢在你前面下单，把价格推高，再卖给你赚差价（叫"抢跑"或"三明治攻击"）。在 Pulse 里，同一个区块里大家的价格都一样，谁先谁后不影响价格，所以这种套路赚不到钱。

> 这是测试网，用的都是**不值钱的测试币**，随便试，不会亏真钱。

## 二、名词小词典

| 词 | 意思 |
|---|---|
| **钱包** | 你的"账户"，这里用 MetaMask 浏览器插件 |
| **测试网** | 一个练习用的区块链，币没有价值 |
| **MON** | 测试网的"手续费币"，每次操作要花一点点 |
| **pMON** | Pulse 里的"商品"代币，你买卖的对象（测试用） |
| **pUSD** | Pulse 里的"钱"，用来买 pMON（测试用） |
| **区块** | 每 0.3 秒产生一个，也就是一场拍卖 |
| **授权 (Approve)** | 允许 Pulse 合约从你钱包里扣款，每种币只需要做一次 |
| **清算 (Settle)** | 一场拍卖结束后，算出统一价格 |
| **领取 (Claim)** | 拿回你成交的币，以及没用完的押金 |

## 三、准备工作（只做一次）

### 第 1 步：安装钱包
1. 用 Chrome 打开 https://metamask.io ，安装 MetaMask 插件。
2. 按提示创建钱包，**把助记词抄在纸上保管好，不要发给任何人**。
3. 建议新建一个**专门用来测试的钱包**，不要用存了真钱的钱包。

### 第 2 步：领测试手续费币 MON
1. 在 MetaMask 里复制你的钱包地址（以 `0x` 开头的一长串）。
2. 打开官方水龙头 https://faucet.monad.xyz ，粘贴地址，领取 MON。
3. 等几秒，MON 到账后再继续。

> 水龙头的领取额度和限制官方没有公开写明，如果这个水龙头领不到，可以到 Monad 的 Discord 或活动现场向工作人员询问。

### 第 3 步：运行网站
在电脑终端里依次执行：

```sh
cd Pulse/web
npm install
npm run dev
```

看到类似 `Local: http://localhost:5173` 的提示后，用浏览器打开这个地址。

## 四、开始玩（跟着页面操作）

### 1. 连接钱包
点击页面右上角 **"连接钱包"**。MetaMask 会弹窗：
- 点"连接"；
- 如果提示"添加网络 / 切换网络"，点同意。网站会自动帮你切到 **Monad Testnet**。

连接成功后，右上角会显示你的地址和 pMON、pUSD 余额（刚开始是 0）。

### 2. 领测试代币
在左侧"下单"区域点：
- **领 pMON**
- **领 pUSD**

每次点击 MetaMask 会弹出确认窗口，点"确认"。等待几秒，右上角余额会更新，各有 10,000 个。

### 3. 授权

> ⚠️ 先确认你有对应的币：**想买入要先有 pUSD，想卖出要先有 pMON**。没有的话先点上面的"领"按钮，否则页面会提示余额不足。

- 想**买入**：页面会显示 **"先授权 pUSD"**，点它并在 MetaMask 里确认。
- 想**卖出**：页面会显示 **"先授权 pMON"**，同样操作。

授权完成后，按钮会变成 **"提交订单"**。授权额度是 100,000，用完需要再授权一次。

> 💡 如果你的浏览器装了多个钱包（比如 MetaMask 和 Coinbase Wallet），页面右上角会出现一个下拉框，选好要用的钱包再点"连接钱包"。Coinbase 插件可能提示"该网站可能不安全"，这是它对新网站的通用提醒，测试时用 MetaMask 即可。

### 4. 下一个订单
1. 选 **买入** 或 **卖出**。
2. 拖动滑块选价格：
   - 买入：你愿意出的**最高价**；
   - 卖出：你愿意接受的**最低价**。
   - 价格范围是 0.50 到 1.13 pUSD。
3. 填**数量**（比如 10）。
4. 点 **提交订单**，在 MetaMask 里确认。

页面会显示"已确认"，以及**从提交到确认花了多少毫秒**。

> 💡 提示：买入时系统会按你的最高价先冻结 pUSD（押金），拍卖结束后多出来的部分会退还给你。

### 5. 看"脉冲时间轴"
页面上方一排小方块，**每一块就是一个区块（一场拍卖）**：

| 颜色 | 含义 |
|---|---|
| 🟨 黄 | 刚产生，还没最终确认 |
| 🟦 蓝 | 已有人投票确认 |
| 🟩 绿 | 已最终确认，不会再改变 |

方块里的数字是区块号，下方显示**这个区块里有几个订单**，清算后还会显示**成交价格**。

### 6. 清算和领取
在右侧"我的订单"表格里，每个订单的最后一列会随着时间变化：

| 显示 | 你要做什么 |
|---|---|
| 进行中 | 这个区块还没结束，等一下 |
| **清算** 按钮 | 点它，算出这一批的统一价格（任何人都可以点） |
| **领取** 按钮 | 点它，拿到你买到的币和退回的押金 |
| 已领取 | 完成 ✅ |

## 五、想看到"统一价"的效果？

一个人很难做到"两个订单在同一个区块里"，建议**两个人一起玩**，或者自己用两个钱包：

1. A 钱包：**卖出** 100 pMON，最低价 0.90。
2. B 钱包：**买入** 100 pMON，最高价 1.10。
3. 两人**几乎同时**点"提交订单"（要落在同一个 0.3 秒的区块里，需要一点运气，多试几次）。
4. 看时间轴：那个方块会显示 `2 单`，清算后显示成交价。
5. 点清算、领取：
   - 买家按统一价（比如 0.90）买到，而不是自己出的 1.10；
   - 卖家按同一个价格（0.90）卖出。

**同一个区块内，所有人的成交价都是同一个，抢先下单也占不到便宜。**

## 六、看"攻击对比"（最直观的演示）

页面最下方有一个 **攻击对比** 区域，左边是普通交易所（AMM），右边是 Pulse。
模拟的是一个"作恶的出块者"，它可以随意安排区块里交易的先后顺序，用经典的三明治手法对付一个受害者：先自己买入，让受害者买在更高的价格，再自己卖出。

1. 点左边的 **运行攻击**：受害者买到的币**少了约 24%**，攻击者净赚约 231 pUSD。
2. 点右边的 **运行攻击**（需要确认两次交易，第二次是清算）：所有订单按**同一个价格**成交，受害者买得和没有攻击时一样，攻击者**没有任何利润**。

这就是 Pulse 的意义：在同一个区块里，先后顺序不再值钱。

## 七、常见问题

**Q：点"连接钱包"没反应？**
没装 MetaMask，或者浏览器没启用它。装好后刷新页面。

**Q：提示"合约尚未部署"？**
说明网站里没有合约地址。开发者需要先部署合约，地址会自动写进 `web/src/deployments.json`。

**Q：交易失败或一直"等待确认"？**
- 检查钱包里有没有 MON（手续费币）。
- 刷新页面再试一次。
- 公共网络偶尔会限流，等几秒重试。

**Q：订单显示"进行中"很久？**
订单所在区块要结束后才能清算，通常 1 秒内就好。如果没动静，刷新页面。

**Q：买单没成交，钱去哪了？**
没有成交的部分不会丢。点"领取"后，押金会全部退回。

**Q：我买入时价格选得很高，会多花钱吗？**
不会。你选的是"最高价"，实际按统一的成交价计算，多冻结的 pUSD 会退回。

**Q：这些币有价值吗？**
没有。MON、pMON、pUSD 都是测试币，不能兑换成真钱。

**Q：要不要把助记词或私钥给别人？**
**绝对不要。** 任何网站、任何人都不应该向你要助记词。Pulse 不需要，也不会问你要。
